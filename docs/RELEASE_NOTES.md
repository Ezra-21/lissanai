# LissanAI v1.0.0 – Release Notes

**Release Date:** June 10, 2026

## Overview
First stable release of LissanAI – the AI-powered English communication coach
built for Ethiopians pursuing global career opportunities.

## Core Features
| Feature | Description |
|---------|-------------|
| Mock Interviews | AI simulator across 6 job categories |
| Grammar Check | Real-time corrections + clarity scoring |
| Email Drafting | Amharic → polished professional email |
| Pronunciation Coach | Phoneme-level speech assessment |
| Learning Paths | Structured lessons + quizzes + progress |

## Highlights
- Personalized onboarding wizard with goal selection
- Activity heatmap and 7/30/100-day streak badges
- SM-2 spaced repetition for vocabulary
- AI response streaming (p95 latency ~1.1s)
- 38% JS bundle size reduction via lazy loading
- 11 WCAG 2.1 AA accessibility fixes

## System Requirements
- Modern browser with MediaRecorder API (pronunciation)
- OpenAI API key with GPT-4o-mini access

## Known Limitations
- Pronunciation coach requires HTTPS in production
- Weekly email digest delivery may take up to 24 hours
